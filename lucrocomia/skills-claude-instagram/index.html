5 skills do Claude pro Instagram

O que cada uma faz e como instalar.

As 5 que ficaram

1. Legenda · ig-caption-writer

Gancho nos primeiros 125 caracteres, corpo curto e um pedido de ação só.

2. Hashtags · ig-hashtag-strategist

Escolhe 3 a 5 por tamanho (nicho, médias e amplas) em vez de um bloco de 30.

3. Auditoria · ig-humanizer

Revisa a legenda antes de publicar e aponta o que soa a robô.

4. Ganchos · ig-hook-extractor

Desmonta o gancho de um Reel viral e diz qual fórmula ele usa.

5. Perfil · ig-profile-optimizer

Audita nome, bio, link, destaques e fixados.

Como instalar

É um pacote de skills de código aberto (licença MIT): github.com/sergebulaev/instagram-skills. Elas rodam dentro do Claude Code (que tem planos próprios). No terminal:

claude plugin marketplace add sergebulaev/instagram-skills
claude plugin install instagram-skills@instagram-skills

Depois é só pedir em linguagem normal, por exemplo: "escreva uma legenda para este Reel sobre [TEMA]".

O que não é grátis

As skills em si são gratuitas, mas o pacote tem outras que usam serviços externos pagos (para ler dados reais do Instagram ou publicar por você). A gente não usa essas. As 5 acima só mexem em texto.

Nenhuma publica por você: quem decide o que postar é você.
